DREI KAMPF（仮） Ver.0.7 α｜バランス試験版
======================================

GitHub Pagesへの配置：
ZIPを解凍し、中の index.html と assets フォルダを
card-battle リポジトリの公開ルートに置いてください。
特に assets/m01_art.webp がないと M-01 森の狼の絵が表示されません。
（game.js は開発・検証用の参照ファイル。index.html に同じJSを埋め込んであるため
GitHub Pagesでの動作には index.html と assets のみで十分です。）

今回の主な変更：
・タイトル画面（画面全体タップで開始）→ CPU対戦 → リザルト
・対戦中の「タイトル」から中断確認／リザルトから再戦・タイトルへ
・モンスター20種・魔法10種を再設計した50枚の試験デッキB
・M-01 森の狼：1/1・猛進（攻撃可能なら攻撃必須）
・M-03 防壁：攻撃不可。左レーン配置でHP+1
・M-06 自傷：ライフ1を代償に強めのステータス
・M-14 血の契約：ライフと最大ライフを各1減少
・M-17の直接攻撃2、M-20の直接攻撃3
・M-20：味方を生贄にして占有済みレーンへ召喚できる（使用確認あり）
・S-05/S-06は2/3枚ドロー、S-09は味方生贄で2枚ドロー
・CPUが不利な攻撃を控えるよう判断を改善（猛進は例外）
・リザルト：対戦ターン数、カード使用、直接攻撃、手札上限によるドロー不発など
・Ver.0.6.1の手札一覧、キャンセル、攻撃状態表示、ターン終了確認を継承

試遊時に確認したいこと：
1. 序盤に1コストが出せるか、手札溢れが減ったか
2. 中盤・終盤で手札が枯渇しないか
3. 防壁と大型が盤面を硬直させすぎないか
4. 切り札（7-10コスト）を実際に使えるか
5. CPUが無駄な自滅をしなくなったか
6. 試合ターン数、劣勢から逆転できたか

※ すべて初回バランス調整の試作案。正式なカード設定ではありません。
